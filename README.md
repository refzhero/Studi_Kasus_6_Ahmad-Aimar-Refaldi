DESKRIPSI SINGKAT


Program ini merupakan Sistem Manajemen Inventaris Barang yang digunakan untuk menyimpan dan mengelola data barang menggunakan file JSON. Program menyediakan menu untuk menampilkan data, menambahkan barang baru, menyimpan perubahan ke file inventaris.json, dan keluar dari program. Data yang ditambahkan akan tersimpan sehingga dapat digunakan kembali saat program dijalankan.

Program Sistem Manajemen Inventaris berjalan dengan baik. Di awal, sistem menampilkan data yang sudah tersimpan, seperti beras, minyak, ayam, dan barang lainnya. Jika pengguna memilih menu 1, semua data inventaris akan ditampilkan dalam bentuk daftar.
Kemudian, pengguna memilih menu 2 untuk menambahkan barang baru. Nama barang yang dimasukkan adalah kambing, dengan stok 12 dan harga 20000. Program menambahkan data tersebut ke dalam daftar inventaris dan menampilkan pesan Data ditambah.
Setelah itu, program menyimpan data ke dalam file. Pesan “Data tersimpan ke inventaris.json muncul, yang menunjukkan bahwa data kambing berhasil disimpan. Jika pengguna kembali memilih menu 1, data kambing muncul bersama barang lainnya. Ini menjelaskan bahwa penambahan dan penyimpanan data berjalan dengan baik.
Akhirnya, pengguna memilih menu 3 untuk keluar dari program. Program menampilkan pesan “Program selesai.” dan berhenti berjalan.
